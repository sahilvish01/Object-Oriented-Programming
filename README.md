# ⚙️ C++ Foundation: OOP & DSA

A structured learning repository documenting my mastery over Core C++, Object-Oriented Programming (OOP) principles, and foundational Data Structures & Algorithms (DSA). 

## 🎯 Objective
Focused on building a rock-solid foundation for problem-solving and technical placements. This codebase tracks my progression from basic memory management and class architectures to utilizing the Standard Template Library (STL) for optimized solutions.

## 📂 Repository Architecture

### 🏗️ Object-Oriented Programming (Core C++)
* **`01.Basics`:** Core syntaxes, I/O operations, and C++ fundamentals.
* **`02.Encapsulation`:** Data hiding, access modifiers, and class structures.
* **`03.Abstraction`:** Implementing functions that accept and return objects.
* **`04.Constructors`:** Object initialization and Dynamic Constructors.
* **`05.Destructor`:** Memory cleanup and destructors for dynamically allocated memory.
* **`06.Friend-Function`:** Bridging access across multiple classes safely.
* **`07.Message-Passing`:** Object communication and method invocation.
* **`08.Static-Keyword`:** Class-level variables, methods, and memory scope.
* **`09.Inheritance`:** Single-level inheritance utilizing the public visibility mode.
* **`10.Polymorphism`:** Interfaces, method overriding, and dynamic binding.

### 🧠 Data Structures, Algorithms & STL
* **`11.Patterns`:** Logic building and nested loops (e.g., Hollow Diamond).
* **`12.Bitwise-Operator`:** Binary level manipulation and conversions (Binary to Decimal).
* **`13.Array`:** Array manipulation and optimal approaches (e.g., Pair Sum problem).
* **`14.STL-Library`:** Utilizing the Standard Template Library (e.g., Unordered Maps) for optimal time and space complexity in problem-solving.
